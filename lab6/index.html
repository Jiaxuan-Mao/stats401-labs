4. Design Description

I use rectangle area to represent GDP because GDP is a positive quantitative variable. This helps compare each country's contribution to the total GDP of the listed countries. I use color to show the direction of change: teal represents Increase, gray represents Unchanged, and pink represents Decrease. Since the data only show the direction rather than the exact growth rate, I use three categories instead of a continuous color scale. Both charts use the same legend. Nested boundaries and headings show continent and area groups, while country labels and tooltips provide details.

The first treemap uses Squarify, which favors compact rectangles that are easier to compare and label. The second uses SliceDice, which alternates the direction of subdivision across hierarchy levels. This highlights the hierarchy but can create long, thin rectangles. I wrap or rotate labels and use external labels with guide lines for very small countries. Both treemaps use the same hierarchy, value order, and chart size. Small countries remain difficult to label, and padding and headings affect visible area proportions. Tooltips therefore provide exact values.
