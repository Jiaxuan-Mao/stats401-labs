4. Design Description

I use rectangle area for GDP because GDP is a positive quantitative variable and treemaps support part-to-whole comparison. Color represents the direction of change: teal for Increase, gray for Unchanged, and pink for Decrease. The neutral middle category separates the two directions without implying a measured growth rate. Both charts use the same legend. Nested boundaries and headings identify continents and areas, while country labels and tooltips provide names, full hierarchy paths, GDP values, and status.

The first treemap uses Squarify, which favors compact rectangles that are often easier to compare and label. The second uses SliceDice, which alternates horizontal and vertical subdivision across hierarchy levels, making the layered structure apparent but often producing thin strips. Labels wrap or rotate; very thin countries use external labels and guide lines. Both retain the same hierarchy, descending value order, and canvas dimensions, so the comparison focuses on segmentation. Small countries remain harder to label, and padding and heading space affect visible area proportions; tooltips provide exact values. The data are synthetic, so the charts illustrate visualization design rather than real economic trends.
