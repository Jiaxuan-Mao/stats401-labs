STATS 401: Data Acquisition and Visualization

Lab 3: Web Data Acquisition with Python

1. Dataset Description

This dataset contains 2,000 television shows collected from TVmaze on September 2, 2026. Each record contains information such as the show's name, type, language, genres, status, premiere date, runtime, rating, network, and country.

2. Data Source and Acquisition

I used the TVmaze Show Index API. Python and the requests library were used to retrieve JSON data. The script uses pagination to collect 2,000 unique shows and pauses for one second between requests.

Basic error handling is included through request retries, rate-limit handling, response validation, and duplicate ID removal. And the collected data is flattened and saved as data/lab3_data.csv.

3. Dataset Attributes

The CSV contains 12 fields:
id, name, type, and language;
genres, status, premiered, and runtime_minutes;
rating, network, country, and show_url.

Runtime is measured in minutes, and rating is on a 0–10 scale. Shows omitted from the TVmaze index are not included in the CSV, which is why the ID sequence contains gaps. For the 2,000 included shows, unavailable field values are retained as missing and displayed as N/A rather than replaced with zero. network records the available broadcast network or streaming platform provided by the source.

4. Interactive Table

Click a column heading to sort the data in ascending order. Click the same heading again to sort in descending order. Missing values are displayed as N/A and sorted last. Ratings and runtimes are sorted numerically. Click a show name to open its TVmaze details page in a new tab.
