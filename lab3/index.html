Data Acquisition

1. Source and Method

I used the TVmaze show index API rather than HTML scraping. My Python script uses requests to retrieve JSON, flattens nested attributes, joins multiple genres with a vertical bar, and saves 12 columns in data/lab3_data.csv. This is the first 2,000 unique shows encountered in API index order, not a random sample or a top-rated list.

2. Pagination and Error Handling

The script starts at page 0 and advances automatically. Each page has up to 250 shows; deleted entries mean some pages are shorter. This collection used 9 pages, with a one-second delay between requests. The script retries temporary errors, pauses after rate-limit responses, checks IDs and numeric ranges, removes duplicate IDs, and saves only after collecting 2,000 unique records. Existing output files are protected from accidental overwriting.

3. Attribute Meaning and Data Quality

Runtime is measured in minutes and the TVmaze average rating is on a 0–10 scale. Network / Platform uses the broadcast network when available, otherwise the streaming platform. Network Country describes that platform's country, not necessarily the show's production country; global platforms can have no country listed. Missing source values remain blank in the CSV, rather than being replaced with zero. Ratings and show status may change.

4. Source Credit and Responsible Use

Data source: TVmaze. The selected and flattened dataset is shared under CC BY-SA 4.0, the same license as the source API data. Changes are limited to selecting records, renaming columns, and flattening nested fields. The public API permits this use with attribution and ShareAlike. Requests are sequential and rate-limited; no login restrictions are bypassed or private data collected.
