STATS 401: Data Acquisition and Visualization

Lab 2: Multivariate Visualization with D3

This visualization explores population, temperature, development level, and region across different cities.

Design Justification

1. Visual Channels

This visualization represents four dimensions of the city dataset using different visual channels. Population is represented by circle size, temperature by vertical position, development level by color, and region by horizontal grouping.

2. Why These Mappings?

I chose these mappings based on the types and characteristics of the attributes. Temperature is an interval attribute, so the y-axis provides a clear way to represent and compare its numerical values. Region is a nominal attribute, so I use categorical groups on the x-axis rather than a continuous numerical scale. Population is a ratio attribute, but I use circle size because the y-axis is already used for temperature; using another quantitative variable on the same axis would make the visualization confusing. Development level is an ordinal attribute, so I use a light-to-dark color scale to show its ordered levels while keeping them within the same visual category.

3. What Should Viewers Notice?

I hope viewers can explore each city by hovering over its circle to see detailed information and notice relationships among the variables, such as darker circles tend to be larger, suggesting that cities with higher development levels tend to have larger populations.
